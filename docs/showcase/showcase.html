StatsCraft

A lightweight statistical workbench, written in Rust.

v0.2.0 Native desktop Rust + egui MIT Windows & Linux
Data Editor01
Spreadsheet grid: click a cell, double-click to edit, Delete to clear.
Variable View02
Types, labels, value labels, missing values, measure and role. Deleting a variable asks first.
Output Viewer03
Pivot tables with an outline, cell statistics and a Pivot button.
Syntax Editor04
Menus and dialogs emit command syntax; one runner executes it.
18 procedures
Frequencies, Descriptives, Crosstabs, t-tests, ANOVA, Correlations, Regression, Means, Explore, Reliability, Factor, ROC, and the nonparametric family.
CSV & .sav
Reads and writes system files: labels, value labels, measures and display widths intact.
107 tests
Every procedure checked against closed-form reference values, and the GLM against statsmodels.
Dialog → syntax
Menus and dialogs emit command syntax; one runner executes it. Light and dark themes.
