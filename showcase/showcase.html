StatsCraft

A lightweight statistical workbench, written in Rust.

Native desktop Rust + egui MIT Windows & Linux
Data Editor01
Spreadsheet grid — click a cell, double-click to edit, Delete to clear.
Variable View02
The full variable column set: type, label, values, measure, role.
Output Viewer03
Pivot tables with detailed notes; export to Markdown or HTML.
Syntax Editor04
Menus and dialogs emit command syntax; one runner executes it.
7 procedures
Descriptives, Frequencies, Crosstabs, Correlations, Regression, T-tests, One-Way ANOVA.
CSV & .sav
Reads `.sav` system files with labels, value labels, measure and user-missing intact.
23 tests
Every procedure checked against closed-form reference values, not against itself.
One .exe
Silent per-user installer, no admin rights, no archive extraction.
